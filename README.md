# Galaxia Carlos y Karla — versión de un solo archivo

Esta versión contiene todo el diseño y las animaciones dentro de `index.html`, evitando errores por carpetas `src` faltantes en GitHub Pages.

## Publicar
1. Sube `index.html` y la carpeta `assets` a la raíz del repositorio.
2. En Settings > Pages selecciona la rama main y /root.
3. Espera 1 a 3 minutos y recarga con Ctrl+F5.

## Canción
Coloca el MP3 en `assets/music/nuestra-cancion.mp3`.
